# MIDG Academy website

Animated one-page website for MIDG Academy of Education Services.

`index.html` is the page. Images and the prospectus PDF sit beside it. Deploy the repository root as a static site (Vercel: Framework "Other", no build command).

Replace `REPLACE-WITH-YOUR-DOMAIN` in `index.html`, `robots.txt` and `sitemap.xml` with the real domain.
